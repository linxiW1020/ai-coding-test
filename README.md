# Codex 本地开发工作流试点

本仓库承载一套 Codex-only 的最小开发闭环：任务与验收条件 → 独立工作树实现 → 本地检查 → 提交 → 新会话审查 → 推送 → Chrome 创建或复用 PR → CI 反馈修复 → 门禁判断 → 合并 → 主分支检查。

运行入口及完整说明见 `controller/README.md`。首版单任务运行，不包含部署和通用工作流平台。

`src/ci_status.py` 是**明确构造的试点缺陷**：初始聚合函数把非空的失败状态字符串当成真值。初始基础测试通过，控制器的独立验收能检出问题。它用于检验自动修复链，不代表客户业务或生产结果。

首次初始化提交以及后续提交、推送、仓库规则、PR 及合并均须按已确认授权执行。真实运行状态见 `controller/VERIFICATION.md`，测试通过不能替代实际 GitHub 闭环或用户验收。
